# 可信短片制作工作台

从一个题目开始，让一位 Agent 查证、设计、制作并交付短片。所有确认都在这个页面完成；聊天里的意见不算批准。可以在全片或单镜截帧、画框和批注，修改后在原时间位置对照新旧画面。

## 启动

Mac 可双击 **启动工作台.command**。也可以在本目录运行：

```sh
git clone https://github.com/Alexuvcarlos/evidence-video-skill.git
cd evidence-video-skill
npm ci
npm start
```

浏览器访问 **http://127.0.0.1:4173**。项目默认保存在本目录的 `data/`，可用 `EVIDENCE_VIDEO_DATA` 指定其他位置。网页可通过「体验示例」生成一支有实际配音和字幕的样片。

## 从题目到交付

```
brief（创作简报）
→ 证据
→ 旁白
→ 分镜与美术
→ 镜头制作
→ 全片审阅（截帧/区间批注）
→ 交付
```

新建项目后先进入**创作简报**：先确认人工检查档位（关键阶段／全流程／Agent 自己完成），再由 Agent 做一轮轻量参考扫描，给出制作方式建议（二维图解／写实三维／混合／实拍／生成）、1–3 个带图风格方向，以及是否允许付费生成、币种、上限和类别。用户在页面里选定并确认后才开始检索。预算与花费都记在项目里，付费调用前必须核对余额。

工作台收到制作请求即检查环境，并把本机可用的配音、截图等能力列在简报页。可以从「制作环境」配置工具路径。

## 审阅与修改

分镜页把每一镜的旁白、对应事实（事实/推断/展望）、原文链接与位置、本镜参考板（带图，标明事实依据/现实参考/美术参考）和动效方案放在同一屏。每镜至少需要一张带图的美术参考；`写实三维` 镜头还需要带图的现实参考，并尽量和旁白事实同源，不同源时必须在分镜里写明原因和最相近场景。

每镜还要写 `motionPlan`：什么元素在动、按什么节拍动、怎么转场。新项目至少一半镜头要用构建、动态字、三维或混合动效，不能整片都是静态页加推拉；风格帧只是参考帧，不是交付物。

全片审阅页可以直接播放；暂停后「截帧批注」或「区间批注」，圈出问题并写下要改什么，再点「按批注修改」。确认与退回只在这个页面完成。

## Agent 接入

任务协议见 `.agents/skills/evidence-video/references/jobs.md`。不依赖特定 CLI 的读取/提交方式：

```sh
node bin/agent.mjs projects          # 列出项目
node bin/agent.mjs status --project <id>
node bin/agent.mjs next --project <id>       # 打印当前任务与结果路径
node bin/agent.mjs submit result.json --project <id>
node bin/agent.mjs wait --project <id>       # 等下一阶段或审阅点
```

Agent 只负责写 `result.json`；确认、合片、字幕、溯源报告由工作台完成。用户在工作台确认或批注后，在对话里说「继续」「我已确认」或「我已修改」即可，不需要复制任务路径。

## 环境

- Node.js 22 及以上、FFmpeg 和 FFprobe。内置静帧、矢量图和字幕烧录使用 sharp。中文绘图依赖系统中文字体。
- 默认调用已登录的 Codex CLI；也可以在「制作环境」把连接方式切到「交给当前对话」。任何能读文件、跑命令的 Agent 都可以用上面的 CLI 接手。
- 联网和第三方工具取决于 Agent 当前的配置。付费生成须先在简报里授权，调用后登记花费。
- 有 Chromium 或 Chrome 时同步生成 PDF；没有时交付页会提示用浏览器打印。

## 验证

```sh
npm run check
npm run demo
```

`.agents/skills/evidence-video/` 保存流程和任务协议，`public/` 保存网页，`lib/` 负责校验、媒体和交付，`bin/agent.mjs` 是跨 Agent 的任务入口，`examples/` 是可公开使用的示例。正式项目、素材、授权和账号配置留在各自的本地环境。
